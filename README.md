# 财务报表单位换算批量工具

一个用 Python 把报表金额从「元」批量换算成「万元 / 千元」并统一小数位的命令行小工具，让财务每月出表从重复手工活变成一条命令。

## 痛点

- 财务每月出报表，需要把「元」换算成「万元 / 千元」，并统一保留两位小数（或整数）。
- 手工处理 **[3]** 份报表要 **[15]** 分钟，且复制粘贴、四舍五入容易出错。
- 报表一多，重复劳动占时间，还很难保证每份口径完全一致。

## 效果对比

| 项目 | 手工处理 | 本工具 |
| --- | --- | --- |
| 处理 [3] 份报表 | [15] 分钟 | **[X] 分钟** |
| 出错风险 | 高（复制 / 四舍五入） | 低（Decimal 精确换算） |
| 数字一致性 | 需逐份核对 | 抽查 [5] 个数字全部一致 |

> 注：`[X]` 请替换为实际测算的处理耗时。

## 快速开始

环境要求：Python 3.10+

```bash
# 1. 安装依赖
pip install pandas openpyxl

# 2. 把待处理的 Excel 文件放进 data 文件夹
#    data/report_01.xlsx
#    data/report_02.xlsx
#    ...

# 3. 运行转换
python convert.py

# 4. 结果在 output 文件夹

#    output/report_02.xlsx
#    ...
```

## 技术方案

- **Python**：脚本语言，逻辑清晰易维护。
- **pandas**：读取、清洗、批量处理 Excel 表格数据。
- **openpyxl**：读写 `.xlsx`，保留表格格式。
- **Decimal**：金额换算使用 `Decimal` 而非浮点，避免精度丢失与四舍五入误差。

## 已知问题

- 目前仅支持固定模板的报表（表头、列位置需一致），未做表头自动识别。
- 单位与小数的换算规则写在代码里，未做成配置文件。
- 暂不支持合并单元格、多 sheet 复杂报表的自动处理。
- 运行前需手动安装 `pandas`、`openpyxl` 依赖。
